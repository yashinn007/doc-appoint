<h1>Project name: Doc Appoint</h1>
<p> Description: A Doctor Appointment Booking System where users can browse available doctors, view details, and book appointments. Users can manage their bookings and profile using secure authentication.</p>

<h2>Technologies:</h2>
1. Next.js,<br/>
2. Hero UI,<br/>
3. Better Auth,<br/>
4. Swiper Slider,<br/>
5. MongoDB,<br/>
6. Tailwind CSS,<br/>
7. Express.js

<h2>Features:</h2>
1. Users can Book & Update Appointment after authentication,<br/>
2. Debounce Search Implemented,<br/>
3. Proxy & JWT implemented for security,<br/>
4. For Backend Express.js & MongoDB has been used,<br/>
5. User can swipe the theme into Dark & Light,<br/>
6. User can change there profile name & image also.
